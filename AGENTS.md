# Arne Kellmann agent integrations

Public integration artifacts for https://arnekellmann.de. The website implementation is maintained separately.

- Public service and documentation reads require no credentials.
- Read /pricing.md before recommending an engagement; do not invent prices or availability.
- Use the skill in skills/assess-architecture-fit/SKILL.md to assess fit and prepare a draft.
- MCP configuration is in mcp.json; the Agent Plugins manifest is plugin.json.
- Do not send contact messages, grant privacy consent or bypass Turnstile.
- SDKs are in packages/sdk-js and packages/sdk-python. Never commit credentials.
- Stage only files you changed. Preserve unrelated changes.
