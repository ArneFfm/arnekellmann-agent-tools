# ChatGPT developer-mode demo

[Watch the demo](https://raw.githubusercontent.com/ArneFfm/arnekellmann-agent-tools/main/docs/demos/arnekellmann-chatgpt-demo.mp4)

Recorded on 2026-09-08 against the live anonymous MCP endpoint at https://arnekellmann.de/mcp using the Arne Kellmann app in ChatGPT Developer Mode. This 60-second edited walkthrough uses actual UI captures from a completed conversation; it is not an uninterrupted recording or a simulated response. No audio.

The conversation calls `list_services` in English and German, `read_document` for `/pricing.md`, and `search_docs` for `architecture`. It displays the tool inputs, returned public information and ChatGPT's summary of four services at EUR 120 per hour excluding VAT, with contact guidance. It does not book, send messages or take payments.
